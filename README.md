# بجاج قنا CRM

نظام إدارة علاقات العملاء (CRM) الخاص بشركة بجاج قنا — إدارة العملاء، الصفقات، المتابعات، الدفعات، الليدز، والمستندات، بواجهة عربية بالكامل (RTL).

**الموقع المباشر:** https://bajajqena-crm.com

## التقنيات المستخدمة

| الطبقة | التقنية |
|---|---|
| الباك إند | PHP 8.2 / Laravel 12 |
| الفرونت إند | Blade + HTML / CSS / JavaScript (بدون build step) |
| قاعدة البيانات | MySQL |
| تصدير/استيراد Excel | PhpSpreadsheet |
| توليد PDF | mPDF |

## هيكل المستودع

```
crm/                  تطبيق Laravel (الكود الكامل للمنصة)
guide/                دليل استخدام المنصة (HTML + PDF)
مستندات-العمل/        نماذج ومستندات العمل الأصلية (إقرارات، أقساط، عروض أسعار... إلخ)
legacy/               نسخة قديمة من نظام سابق، للرجوع إليها فقط
```

## التشغيل محلياً

```bash
cd crm
composer install
cp .env.example .env
php artisan key:generate
# اضبط بيانات قاعدة البيانات في .env ثم:
php artisan migrate
php artisan serve
```

المشروع لا يحتاج خطوة build لأصول الواجهة (CSS/JS تُقدَّم مباشرة من `public/`)؛ إعدادات Vite/Tailwind الموجودة في `package.json` غير مُستخدمة فعليًا في التطبيق الحالي.

## الاختبارات

```bash
cd crm
php artisan test
```
